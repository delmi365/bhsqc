# 三本关于亲密关系的书

> 一位读者丢给我两份素材——一张写着"生存价值与繁殖价值"的笔记照片，和一份 25.8 万字的网络文档《两性关系实战指南》（10 章 / 172 篇，其中一部分是图片 OCR 出来的）。我把它重编成了三本书。

这三本书是同一套工作流的产物：**去重 → 结构重建 → 内容改写 → 补充缺失 → 编译成书**。仓库里既有成品，也有全部 Markdown 源稿和构建脚本，改完源稿可以一键重新出书。

---

## 一、三本书分别是什么

### 1. 《价值交换：亲密关系中的生存价值与繁殖价值》

**素材**：一张关于"生存价值 / 繁殖价值"的笔记照片（几百字）

把一段碎片化的笔记，展开成一本 16 章 + 5 个附录的完整手册。核心是修正一个常见误解：**关系里的交换，交换的不是条件清单，是体验**。

- 结构：4 个部分，16 章 + 5 个附录（30 天路线图、自评量表、速查表、50 条误区、延伸阅读）
- 规模：约 3.7 万字，118 个小节，18 张表
- 源稿：`src/`，构建：`python build.py`

### 2. 《不套路：从认识到长期关系的实操手册》

**素材**：那份 25.8 万字文档（172 篇，去重后 164 篇）

原素材经验很具体，但有三个问题：重复得厉害（8 组全文重复）、术语体系自带 PUA 立场、有一部分内容涉及同意红线。这本书保留了可操作的部分，**删掉了操控性的部分，并补上了原稿完全没有的两块内容**。

- 结构：6 个部分，26 章 + 4 个附录（164 篇原始条目索引、删改对照表、术语替换表、OCR 错字表）
- 规模：约 4.3 万字，142 个小节，37 张表
- 删改：见书内前言与附录 B。删除了猫绳理论、推拉打压、ASD/LMR"破解"、多重长期关系、酒精相关指导、性别全称判断、伪进化论论证；整段重写了关于安全套的错误段落
- 补充：第 18 章"同意"、第 19 章"性健康与安全"——原稿 164 篇里**没有一篇**正面写过这两件事
- 源稿：`src2/`，构建：`python build2.py`

### 3. 《把话说清楚：关系场景对话与回应手册》

**素材**：同上（散落在长文里的对话经验）

前一本讲流程和判断，这一本专讲"**具体说什么**"——118 个场景，每个场景统一给出：别这样说 / 可以这样说 / 为什么。

- 结构：6 个部分，20 章 + 3 个附录（错误说法→正确说法速查表、万能句式库、21 天对话练习）
- 规模：118 个场景条目，约 2.7 万字
- 补充了原素材几乎没有的部分：拒绝别人、被纠缠怎么办、提需求、设边界、危险与不适场景的回应、分手的措辞
- 源稿：`src3/`，构建：`python build3.py`

## 二、目录结构

```
.
├── index.html              # 仓库首页（GitHub Pages 可直接用）
├── app.html                # 手机 App 版《把话说清楚》（单文件，离线可用，可存主屏）
├── app_data.json / app_data.js  # App 的数据源（由 src3 生成，已内嵌进 app.html）
├── output/                 # 成品：每本书 3 种格式
│   ├── 价值交换_生存价值与繁殖价值_电子书.html / .epub / _全书手稿.md
│   ├── 不套路_从认识到长期关系的实操手册_电子书.html / .epub / _全书手稿.md
│   └── 把话说清楚_关系场景对话与回应手册_电子书.html / .epub / _全书手稿.md
├── src/  src2/  src3/      # 三本书的 Markdown 源稿（改这里）
├── build.py  build2.py  build3.py   # 构建脚本（无第三方依赖）
├── mk_appdata.py / mk_app.py       # 由 src3 生成 App 数据并打包成 app.html
├── mk_appendix.py          # 从原始素材生成《不套路》附录 A 的条目索引
└── verify.py  verify2.py  verify3.py  # 出书后自检（章节数、表格数、EPUB 完整性等）
```

## 三、成品怎么用

| 格式 | 用途 |
| --- | --- |
| `_电子书.html` | 单文件，双击就能看。带封面、侧边目录、阅读进度条、右上角"打印 / 存 PDF" |
| `.epub` | 导入微信读书、Apple Books、Calibre、Kindle 等阅读器 |
| `_全书手稿.md` | 合并后的纯文本，方便检索、二次编辑或导入笔记软件 |

**手机 App 版**：`app.html` 是《把话说清楚》的手机阅读 App——顶栏搜索、已读进度、卡片式「别这样说 / 可以这样说 / 为什么」。数据内嵌、单文件、离线可用，用手机浏览器打开后"添加到主屏"即可当原生 App 用。

**在线阅读**：把仓库推到 GitHub 后，Settings → Pages → Branch 选 `main`、目录选 `/ (root)`，等一两分钟就能用 `https://<用户名>.github.io/<仓库名>/` 打开首页，三本书都能在线翻，`app.html` 也在同一目录下。

## 四、改稿与重新出书

需要 Python 3.8+，不装任何包即可：

```bash
python build.py      # 出《价值交换》
python build2.py     # 出《不套路》
python build3.py     # 出《把话说清楚》
python verify.py     # 出完自检（同理 verify2/verify3）
python mk_appdata.py # 由 src3 生成 app_data.json / app_data.js
python mk_app.py     # 由 app_data.json 打包成单文件 app.html
```

产物会写进 `output/`，自检报告写进 `output/_report*.txt`（已在 `.gitignore` 里忽略）。

想改内容就改 `src*` 里的 Markdown：`#` 是一章，`##` 是一节，`|` 开头是表格，`>` 是引用。改完重跑构建即可，封面、目录、EPUB 导航都会自动跟着变。

## 五、没有放进仓库的东西

- **原始素材**（`material/`，含 768 KB 的 `data.json`、各章原文与五份 digest）**没有上传**。那份文档是网络上他人的作品（且带 OCR 错误），不适合公开分发；同时它也不是阅读成品所必需的。
- 因此 `mk_appendix.py` 在本仓库里无法直接运行（它依赖 `material/unique.json`）。如果需要对着原稿核对，把素材放进 `material/` 后即可运行。
- 素材解析脚本（`dump.py`、`dedupe.py`）同理未包含。

## 六、关于内容与授权

三本书均由 AI 基于上述素材重编，其中：

- 可操作经验部分（自我建设、聊天、约会、长期关系维护、防骗识别）来自原始素材；
- 涉及**同意、性健康、拒绝与边界、危险场景应对**的内容，为本次编写时补充；
- 原素材中带有操控性质、物化倾向或缺乏依据的断言，已逐条删除或改写，并在《不套路》附录 B 中列明。

书中涉及心理学与行为科学的常识性表述按通行共识处理，**不构成专业心理或医疗建议**。
